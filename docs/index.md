# icat

`icat` prepares ROM files, metadata and thumbnails for an IGUI game catalogue.
It runs on the PC; it does not configure emulators, install BIOS files or verify
that a game runs on the target device.

The PyPI distribution is `iboxed-icat`; the Python package and CLI command are `icat`.
