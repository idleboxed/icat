# Инструкции агента

Используй [IDLE.md](IDLE.md); уточнения этого проекта имеют приоритет.

## Проект

`icat` — переносимое CLI-приложение на Python для подготовки каталога игр IGUI на ПК.
Оно проверяет и импортирует самодостаточные ROM, включая образы из ZIP/7z и CHD,
дополняет их метаданными и превью из внешних источников.
Каталог публикуется после синхронизации файлов, а удаление исходников разрешено
только после проверки результата и неизменности исходных данных.
Код разделён по предметным пакетам в `src/icat/`, тесты повторяют их иерархию
и используют синтетические данные без реального оборудования и внешней сети.

## Уточнения

- Имя дистрибутива для PyPI — `iboxed-icat`; Python-пакет и команда — `icat`.
- Локальная установка CLI: `ma up --tool`; разработка и проверки:
  `ma tools` и `ma tests` из каталога пакета, только на Python 3.12.
- Wheel содержит пакет, метаданные и лицензию; sdist включает также тесты и их данные.
- Новые команды и параметры CLI, изменение проверок безопасности и патчи сторонних
  зависимостей требуют предварительного явного согласования с владельцем.
